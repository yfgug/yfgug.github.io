TrailSnap - 徒步照片管理应用

📸 什么是TrailSnap？

TrailSnap是一个专为徒步爱好者设计的照片管理应用，可以自动整理、分类和展示你的徒步照片。

项目地址

  • GitHub：yfgug/TrailSnap

✨ 功能特点

1. 智能分类

  • 自动识别照片中的地点
  • 按徒步路线整理照片
  • AI识别风景类型（山峰、草甸、溪流等）

2. 路线追踪

  • 记录GPS轨迹
  • 照片自动关联到路线点
  • 生成徒步路线图

3. 时间线展示

  • 按时间顺序展示照片
  • 支持按路线、地点筛选
  • 生成徒步回忆录

4. 数据安全

  • 本地部署，数据完全私有
  • PostgreSQL数据库存储
  • 支持Docker一键部署

🛠️ 技术栈

组件 技术
前端 Vue.js / React
后端 Python (FastAPI)
数据库 PostgreSQL + pgvector
AI服务 图像识别、地点提取
部署 Docker Compose
